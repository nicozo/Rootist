# Quickstart: 確かめ方

## 自動テスト（エージェントが通す）

CLAUDE.md の「Commands」のとおり Docker の `tools` で `pnpm check` / `pnpm lint` / `pnpm test:unit -- --run` / `pnpm test:e2e` を通す。Supabase には接続せず、サーバーのテストは `locals.supabase.auth` をモックする。どの要件をどの層で確かめるかは [plan.md](./plan.md) の「テストの分担」。

## 師匠に頼む準備（実値が要るもの）

1. Supabase ダッシュボード → Authentication → Providers → Email: Email OTP Length = 6、Email OTP Expiration = 600
2. Email Templates の「Magic Link」「Confirm signup」を、`{{ .Token }}` を表示する日本語の文面に変える
3. Custom SMTP を設定する（本番。開発は標準の送信でも数通なら届く）
4. Authentication → Passkeys を有効にし、Relying Party ID・Origins（本番と開発の origin）を入れる

手順の正は `docs/supabase-setup.md` に追記する（実装の PR で）。
