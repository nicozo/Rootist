## 依頼文（全文固定。あり／なしで同一。Context7 の使用・不使用は指示しない）

> `src/lib/styles/utilities.css` を新設して、次の 3 つを Tailwind CSS v4 の CSS だけの書き方で定義してください。(1) 静的ユーティリティ `scrollbar-hidden`（スクロールバーを非表示にする。Firefox と WebKit の両方で効くこと）。(2) 値を受け取るユーティリティ `tab-*`（`tab-4` で `tab-size: 4`。整数だけを受け付ける）。(3) バリアント `sepia:`（`data-theme="sepia"` が自身または祖先に付いているときに適用）。このファイルは他の CSS から `@import` される前提なので、`@import 'tailwindcss'` は書かないでください。

## 正解の根拠

### 正しい API（このバージョンで有効）

- `@utility scrollbar-hidden { ... }`（静的ユーティリティ。`&::-webkit-scrollbar` をネストできる）
- `@utility tab-* { tab-size: --value(integer); }`（値を受け取る関数形ユーティリティ。`--value(integer)` は整数だけを許可）
- `@custom-variant sepia (&:where([data-theme='sepia'], [data-theme='sepia'] *));`

### 廃止・存在しない API（判定の参照表）

| API                                                                                                      | 状態                                                                                 | 備考             |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ---------------- |
| `@layer utilities { .scrollbar-hidden { ... } }`                                                         | v3 の書き方。v4 ではユーティリティとして登録されず、バリアント（`sepia:`）も付かない | 廃止（v3 方式）  |
| `tailwind.config.js` の `plugins: [plugin(({ addUtilities }) => ...)]` / `matchUtilities` / `addVariant` | v3 の JS 設定。v4 は CSS-first                                                       | 廃止（v3 方式）  |
| `@tailwind base;` / `@tailwind components;` / `@variants { }` / `@responsive { }`                        | v3 のディレクティブ。v4 では `@import 'tailwindcss'` に統一、`@variants` は廃止      | 廃止             |
| `--value(number)` で整数を期待して `tab-1.5` を通す                                                      | `integer` と `number` は別。要件は整数のみ                                           | 完了条件の不合格 |

### 出典

- 公式ドキュメント（カスタムユーティリティ・関数形ユーティリティ・カスタムバリアント）: https://tailwindcss.com/docs/adding-custom-styles
- v3 からの移行（`@layer components` → `@utility` など）: https://tailwindcss.com/docs/upgrade-guide

既存の関連使用例は `src/routes/layout.css` の `@custom-variant dark (&:is(.dark *));` と `@theme inline`（shadcn 由来）。`@custom-variant` の書式は写せるが、`@utility`（静的・関数形）は写せない。

## 判定用テスト（`src/lib/styles/utilities.test.ts` に置く。固定前に使い捨て worktree で red / green を確認済み。結果は docs/context7-benchmark/README.md の「固定時の確認」）

```ts
import { readFileSync } from 'node:fs';
import { compile } from 'tailwindcss';
import { describe, expect, it } from 'vite-plus/test';

// C7-TW-01 判定用テスト: src/lib/styles/utilities.css を Tailwind CSS v4 でコンパイルして確認する

const css = readFileSync(new URL('./utilities.css', import.meta.url), 'utf8');

async function build(candidates: string[]) {
	// ユーティリティの出力位置を示す内部ディレクティブ（compile API 用）を末尾に足してコンパイルする
	const { build } = await compile(`${css}\n@tailwind utilities;`);
	return build(candidates);
}

describe('utilities.css（Tailwind CSS v4）', () => {
	it('@import "tailwindcss" を含まない', () => {
		expect(css).not.toMatch(/@import\s+['"]tailwindcss/);
	});

	it('scrollbar-hidden: Firefox と WebKit の両方でスクロールバーを隠す', async () => {
		const out = await build(['scrollbar-hidden']);
		expect(out).toContain('.scrollbar-hidden');
		expect(out).toContain('scrollbar-width: none');
		// ネスト形式（&::-webkit-scrollbar）でも展開形式でもよい
		expect(out).toMatch(/::-webkit-scrollbar/);
		expect(out).toMatch(/display:\s*none/);
	});

	it('tab-*: 整数だけを受け取り tab-size を出す', async () => {
		const out = await build(['tab-4', 'tab-8']);
		expect(out).toMatch(/\.tab-4\s*{[^}]*tab-size:\s*4/);
		expect(out).toMatch(/\.tab-8\s*{[^}]*tab-size:\s*8/);
		const none = await build(['tab-x', 'tab-1.5']);
		expect(none).not.toContain('tab-size');
	});

	it('sepia: バリアント。data-theme="sepia" の自身または祖先で効く', async () => {
		const out = await build(['sepia:scrollbar-hidden']);
		expect(out).toContain('sepia\\:scrollbar-hidden');
		expect(out).toMatch(/\[data-theme=['"]sepia['"]\]/);
		expect(out).toContain('scrollbar-width: none');
	});

	it('v3 の書き方（@layer utilities / @tailwind / @variants）を使っていない', () => {
		expect(css).not.toMatch(/@layer\s+utilities/);
		expect(css).not.toMatch(/@tailwind\b/);
		expect(css).not.toMatch(/@variants\b/);
	});
});
```
