## 依頼文（全文固定。あり／なしで同一。Context7 の使用・不使用は指示しない）

> `src/lib/server/db/schema.ts` に、旅行プランへのコメントを入れる `plan_comments` テーブルを追加してください。列は `id`（自動採番の主キー。`plans` と同じ作法）、`plan_id`（`plans.id` への外部キー。プランが消えたら一緒に消える）、`author_key`（文字列・必須）、`body`（文字列・必須）、`status`（PostgreSQL の enum 型 `comment_status` で値は `visible` / `hidden` / `flagged`、既定は `visible`、必須）、`created_at`（タイムゾーン付き・必須・既定は現在時刻）です。インデックスは、`plan_id` と `created_at` の通常のインデックス `plan_comments_plan_created_idx` と、`plan_id` と `author_key` の一意インデックス `plan_comments_plan_author_uq` を作ってください。`plans` と同様に RLS を有効にしてください。エクスポート名は `commentStatus`（enum）と `planComments`（テーブル）です。マイグレーションの生成・適用は不要です。

## 正解の根拠

### 正しい API（このバージョンで有効）

- `pgEnum('comment_status', ['visible', 'hidden', 'flagged'])` と、列での `commentStatus('status')`
- `.references(() => plans.id, { onDelete: 'cascade' })`
- `pgTable(name, columns, (t) => [index(...).on(...), uniqueIndex(...).on(...)])`（第 3 引数は**配列**を返す）
- `.enableRLS()`（既存の `plans` と同じ）

### 廃止・存在しない API（判定の参照表）

| API                                                                                               | 状態                                                                                                          | 備考               |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------ |
| `pgTable(name, columns, (t) => ({ idx: index(...).on(...) }))`（第 3 引数がオブジェクトを返す形） | 0.45.2 の型定義で `@deprecated`（配列形に移行中）。`node_modules/drizzle-orm/pg-core/table.d.ts` の注釈で確認 | 廃止（deprecated） |
| `text('status', { enum: ['visible', ...] })` で DB の enum 型の代用                               | 動くが DB の enum 型にならない（要件は PostgreSQL の enum 型）                                                | 完了条件の不合格   |
| `serial('id')` の主キー                                                                           | 有効だが要件は `plans` と同じ作法（`generatedAlwaysAsIdentity`）                                              | 完了条件の不合格   |
| `references(plans.id)`（アロー関数なし）                                                          | 型エラー（`references` は `() => column` を要求）                                                             | 型エラー           |

## 判定用テスト（`src/lib/server/db/plan-comments.test.ts` に置く。固定前に使い捨て worktree で red / green を確認済み。結果は docs/context7-benchmark/README.md の「固定時の確認」）

```ts
import { getTableConfig } from 'drizzle-orm/pg-core';
import { describe, expect, it } from 'vite-plus/test';
import { planComments, commentStatus } from './schema';

// C7-DZ-01 判定用テスト: plan_comments テーブルの定義（drizzle-orm / pg-core）

describe('planComments', () => {
	const cfg = getTableConfig(planComments);

	it('テーブル名と RLS', () => {
		expect(cfg.name).toBe('plan_comments');
		expect(cfg.enableRLS).toBe(true);
	});

	it('status は pgEnum comment_status（visible / hidden / flagged）', () => {
		expect(commentStatus.enumName).toBe('comment_status');
		expect(commentStatus.enumValues).toEqual(['visible', 'hidden', 'flagged']);
		const status = cfg.columns.find((c) => c.name === 'status');
		expect(status?.getSQLType()).toBe('comment_status');
		expect(status?.default).toBe('visible');
		expect(status?.notNull).toBe(true);
	});

	it('plan_id は plans.id への外部キー（plans 削除時に cascade）', () => {
		expect(cfg.foreignKeys).toHaveLength(1);
		const fk = cfg.foreignKeys[0].reference();
		expect(getTableConfig(fk.foreignTable).name).toBe('plans');
		expect(fk.columns.map((c) => c.name)).toEqual(['plan_id']);
		expect(cfg.foreignKeys[0].onDelete).toBe('cascade');
	});

	it('インデックス: (plan_id, created_at) の通常 index と、(plan_id, author_key) の unique index', () => {
		const byName = Object.fromEntries(cfg.indexes.map((i) => [i.config.name, i.config]));
		expect(byName['plan_comments_plan_created_idx'].unique).toBe(false);
		expect(
			byName['plan_comments_plan_created_idx'].columns.map(
				(c: unknown) => (c as { name: string }).name
			)
		).toEqual(['plan_id', 'created_at']);
		expect(byName['plan_comments_plan_author_uq'].unique).toBe(true);
		expect(
			byName['plan_comments_plan_author_uq'].columns.map(
				(c: unknown) => (c as { name: string }).name
			)
		).toEqual(['plan_id', 'author_key']);
	});
});
```
