## 正解の根拠

### 正しい API（このバージョンで有効）

- `import { Switch as SwitchPrimitive } from 'bits-ui'` のあと `SwitchPrimitive.Root` と `SwitchPrimitive.Thumb`（bits-ui 2.19.0 の `dist/bits/switch/exports.d.ts` は `Root` と `Thumb` の 2 つだけを export）
- `checked` は `$bindable`。`name` を渡すとフォーム用の hidden input が描画される
- 子の描画は `children` / `child` スニペット（`{ checked }` が渡る）。型は `SwitchPrimitive.RootProps`

### 廃止・存在しない API（判定の参照表）

| API                                                                             | 状態                                                                                                                 | 備考                          |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| `Switch.Input`                                                                  | 公開 API に無い。`dist/bits/switch/components/switch-input.svelte` は内部実装で、`exports.d.ts` から export されない | 存在しない API                |
| `Switch.Label`                                                                  | 公開 API に無い（ラベルは別の `Label` を使う）                                                                       | 存在しない API                |
| `<Switch.Root on:checkedChange={...}>` / `on:click` などの `on:` ディレクティブ | Svelte 5 + bits-ui v2 ではコールバック props（`onCheckedChange`）を使う                                              | 廃止                          |
| `let { ... } = $props()` を使わず `export let checked`                          | Svelte 4 の書き方。この issue の対象外（runes mode）                                                                 | 判定対象外（Svelte 側の担当） |
| `bind:checked` 無しで `checked` を props として受け流すだけ                     | 要件（`bind:checked` で状態を受け渡せる）を満たさない                                                                | 完了条件の不合格              |

## 判定用テスト（`src/lib/components/ui/switch/switch.test.ts` に置く。固定前に使い捨て worktree で red / green を確認済み。結果は docs/context7-benchmark/README.md の「固定時の確認」）

```ts
import { render } from 'svelte/server';
import { describe, expect, it } from 'vite-plus/test';
import { Switch } from './index';

// C7-BU-01 判定用テスト: ui/switch を SSR してマークアップを確認する（bits-ui v2 の Switch）

function html(props: Record<string, unknown>) {
	return render(Switch, { props }).body;
}

describe('ui/switch', () => {
	it('index から Switch（Root）を export している', () => {
		expect(Switch).toBeTypeOf('function');
	});

	it('role=switch の button として描画され、checked が反映される', () => {
		const on = html({ checked: true });
		expect(on).toMatch(/<button[^>]*role="switch"/);
		expect(on).toMatch(/aria-checked="true"/);
		expect(on).toMatch(/data-state="checked"/);
		const off = html({ checked: false });
		expect(off).toMatch(/aria-checked="false"/);
		expect(off).toMatch(/data-state="unchecked"/);
	});

	it('data-slot="switch" を持ち、つまみ（thumb）を描画する', () => {
		const out = html({});
		expect(out).toContain('data-slot="switch"');
		expect(out).toContain('data-switch-thumb');
	});

	it('disabled が反映される', () => {
		expect(html({ disabled: true })).toMatch(/data-disabled/);
	});

	it('class を受け取り、マージして出す', () => {
		expect(html({ class: 'my-extra-class' })).toContain('my-extra-class');
	});
});
```
