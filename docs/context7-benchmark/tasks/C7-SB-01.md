## 依頼文（全文固定。あり／なしで同一。Context7 の使用・不使用は指示しない）

> パスワード再設定メールのリンクから戻ってくる口として、GET `/auth/confirm`（`src/routes/auth/confirm/+server.ts`）を作ってください。クエリの `token_hash` と `type` を Supabase Auth で検証してセッションを確立します。`type` は `recovery` のときだけ受け付けます。成功したら `next` クエリが指す同一サイトの相対パス（`/` で始まり `//` で始まらないもの。省略または不正なら `/plan`）へ、失敗・パラメータ不足・`type` が `recovery` 以外のときは `/login?error=confirm` へ、いずれも 303 でリダイレクトしてください。Supabase クライアントは `locals.supabase` を使ってください。生のエラー内容は画面に出さないでください。

## 正解の根拠

### 正しい API（このバージョンで有効）

- `locals.supabase.auth.verifyOtp({ type: 'recovery', token_hash })`（トークンのハッシュを使うリンク方式。email の OTP コード方式の `{ email, token, type }` とは別物）
- 戻り値は `{ data, error }`。`error` を見て分岐する
- `redirect(303, ...)` は try/catch の外で呼ぶ（既存の `/auth/callback` と同じ作法）

### 廃止・存在しない API（判定の参照表）

| API                                                                                                    | 状態                                                           | 備考                                                  |
| ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------- | ----------------------------------------------------- |
| `supabase.auth.api.*`（`resetPasswordForEmail` 等を `auth.api` 配下から呼ぶ）                          | v1 の API。v2 に存在しない                                     | 存在しない API                                        |
| `supabase.auth.session()` / `auth.user()`                                                              | v1 の API。v2 では `getSession()` / `getUser()`                | 存在しない API                                        |
| `verifyOtp({ email, token, type: 'recovery' })`（`token` に 6 桁コードではなくリンクのハッシュを渡す） | email OTP コード用の形。リンクのハッシュは `token_hash` で渡す | 誤用（判定: `token_hash` を渡していない場合は不合格） |
| `verifyOtp({ token_hash, type })` に `type` を未検証のまま素通し                                       | 許可する `type` を絞る要件に反する                             | 完了条件の不合格                                      |
| `exchangeCodeForSession(token_hash)`                                                                   | `code`（PKCE の認可コード）専用。`token_hash` は渡せない       | 誤用                                                  |

## 判定用テスト（`src/routes/auth/confirm/server.test.ts` に置く。固定前に使い捨て worktree で red / green を確認済み。結果は docs/context7-benchmark/README.md の「固定時の確認」）

```ts
import { describe, expect, it, vi, afterEach, beforeEach } from 'vite-plus/test';
import { GET } from './+server';

// C7-SB-01 判定用テスト: GET /auth/confirm（メールのリンクのトークン検証）

const verifyOtp = vi.fn();
const exchangeCodeForSession = vi.fn();

function event(search: string) {
	return {
		url: new URL(`http://localhost/auth/confirm${search}`),
		locals: { supabase: { auth: { verifyOtp, exchangeCodeForSession } } }
		// eslint-disable-next-line @typescript-eslint/no-explicit-any
	} as any;
}

beforeEach(() => {
	verifyOtp.mockResolvedValue({ data: {}, error: null });
	vi.spyOn(console, 'error').mockImplementation(() => {});
});
afterEach(() => {
	vi.clearAllMocks();
	vi.restoreAllMocks();
});

describe('/auth/confirm', () => {
	it('recovery のトークンを検証できたら next（相対パス）へ 303', async () => {
		await expect(
			GET(event('?token_hash=abc&type=recovery&next=/account/password'))
		).rejects.toMatchObject({
			status: 303,
			location: '/account/password'
		});
		expect(verifyOtp).toHaveBeenCalledTimes(1);
		expect(verifyOtp).toHaveBeenCalledWith({ type: 'recovery', token_hash: 'abc' });
		expect(exchangeCodeForSession).not.toHaveBeenCalled();
	});

	it('next が無ければ /plan へ', async () => {
		await expect(GET(event('?token_hash=abc&type=recovery'))).rejects.toMatchObject({
			status: 303,
			location: '/plan'
		});
	});

	it.each(['https://evil.example/', '//evil.example', 'javascript:alert(1)', 'plan'])(
		'不正な next（%s）は /plan へ',
		async (next) => {
			await expect(
				GET(event(`?token_hash=abc&type=recovery&next=${encodeURIComponent(next)}`))
			).rejects.toMatchObject({ status: 303, location: '/plan' });
		}
	);

	it('検証エラーは /login?error=confirm へ（生のエラーは出さない）', async () => {
		verifyOtp.mockResolvedValue({
			data: {},
			error: { code: 'otp_expired', message: 'secret detail' }
		});
		await expect(GET(event('?token_hash=abc&type=recovery'))).rejects.toMatchObject({
			status: 303,
			location: '/login?error=confirm'
		});
	});

	it('例外も /login?error=confirm へ', async () => {
		verifyOtp.mockRejectedValue(new Error('network'));
		await expect(GET(event('?token_hash=abc&type=recovery'))).rejects.toMatchObject({
			status: 303,
			location: '/login?error=confirm'
		});
	});

	it.each([
		'?type=recovery',
		'?token_hash=abc',
		'?token_hash=abc&type=signup',
		'?token_hash=abc&type=magiclink'
	])(
		'パラメータ不足・type が recovery 以外（%s）は検証せず /login?error=confirm へ',
		async (search) => {
			await expect(GET(event(search))).rejects.toMatchObject({
				status: 303,
				location: '/login?error=confirm'
			});
			expect(verifyOtp).not.toHaveBeenCalled();
		}
	);
});
```
