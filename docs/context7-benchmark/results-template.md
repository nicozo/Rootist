列の定義:

| 列                        | 内容                                                                                                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 実施日                    | 試行を実施した日（UTC）                                                                                                                      |
| 課題 ID                   | `C7-SB-01` など                                                                                                                              |
| 条件                      | あり / なし                                                                                                                                  |
| 試行番号                  | 課題 × 条件ごとの通し番号（目安 3 回）                                                                                                       |
| 起点コミット              | 課題ファイルの起点コミットと一致していること                                                                                                 |
| 型 / lint / テスト        | 判定基準 1〜3。「合格 / 合格 / 不合格」のように 3 つをスラッシュで並べる（各 合格・不合格・判定不能）                                        |
| 存在しない API / 廃止 API | 判定基準 4・5（有無。有なら API 名）                                                                                                         |
| 完了条件                  | 判定基準 7（合格・不合格）                                                                                                                   |
| 正答                      | 1〜5 と 7 がすべて合格なら ○、そうでなければ ×                                                                                               |
| Context7 呼び出し         | 集計スクリプトの値（resolve / query-docs）。「なし」は 0 であること                                                                          |
| バージョン一致            | 判定基準 6（一致 / 不一致 / 不明 / 対象外（なし条件））                                                                                      |
| トークン / 所要時間       | 集計スクリプトの「generator トークン」「所要時間」と同じ算出方法（メッセージ ID で重複排除した使用量の合計、タイムスタンプの最小〜最大の差） |
| 運用障害                  | なし / 接続失敗 / キー失効 / レート制限 / その他                                                                                             |
| セットアップ手間          | 実施前の準備にかかった分数（Gateway 起動・キー確認等）                                                                                       |
| 備考                      | 判定不能の理由など                                                                                                                           |
