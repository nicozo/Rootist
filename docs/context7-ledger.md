## 運用ルール

- **行は手で書かない**。`pnpm metrics:context7 -- --dir ~/.claude/projects/-Users-katoukouhei-Dev-rootist/ --dev-loop <メインのワーキングツリー>/.dev-loop --issue <N>` の出力の issue 行を転記し、末尾に備考列を足す（dev-loop の Step 6 が行う）。台帳の表は、フォーマッタが列幅をそろえて文字列が変わるのを避けるため、`text` のコードブロックに入れている（出力の行と文字列で一致させるため）。
- 列は集計スクリプトの issue 別表と同じ（導入前後の区分を含む）＋ 備考。備考には、使用場面ルールの版（改訂したら版を上げ、改訂前後を混ぜて比較しない）や、比較の前提が変わった印を書く。

- 理由: Claude Code はセッション記録を一定期間で削除する（`cleanupPeriodDays`。詳細は measurement.md）ため、集計結果の要約をリポジトリに残す。
