## 要件（Functional Requirements） _(必須)_

<!--
  要件は EARS 記法で、1 行 1 要件の表に書く。

  列:
  - ID: `FR-001` から連番。一度振った ID は変えず、再利用もしない（取り下げても欠番にする）
  - 型: 常時 / イベント / 状態 / 異常 / オプション / 複合 のどれか
  - 項目: 要件の対象を短い名詞で（例: 行き先入力、プラン保存）
  - 要件: 型に合った EARS の文型で 1 文。主語は「システム」
    - 常時: 「システムは、〜する。」
    - イベント: 「〈きっかけ〉とき、システムは〜する。」
    - 状態: 「〈状態〉の間、システムは〜する。」
    - 異常: 「〈望まない状況〉場合、システムは〜する。」
    - オプション: 「〈機能〉がある場合、システムは〜する。」
    - 複合: 「〈状態〉の間に〈きっかけ〉とき、システムは〜する。」
  - 理由: その要件が要る理由（背景・利用者の困りごと）。「何を」の言い換えにしない
  - ステータス: 案 / 確定 / 取り下げ
    - 書き始めは「案」。承認されたら「確定」にする
    - 不要になった要件は行を消さず「取り下げ」にし、理由の列に取り下げた理由を足す

  1 文に「かつ」「または」で複数の振る舞いを詰めない（分けて別 ID にする）。
  検証できない形容詞（速い・使いやすい）は使わず、数値や観察できる状態で書く。
-->
